# thorn91.github.io

This repo only hosts **thomashorn.info**. Its `gh-pages` branch holds the built site, written there by a release from [thorn91/sites](https://github.com/thorn91/sites), and GitHub Pages serves that branch.

The code and its full history now live in `thorn91/sites`, in `apps/personal`. Change and release the site there:

```
npm run ship personal
```

Don't push code here, and don't delete this repo or its `gh-pages` branch: either takes thomashorn.info offline.
